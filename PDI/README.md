# 🖼️ Processamento Digital de Imagens — Equalização e Especificação de Histograma

Projeto desenvolvido para a disciplina de **Processamento Digital de Imagens (PDI)**, com o objetivo de implementar os algoritmos de **equalização de histograma** e **especificação de histograma** utilizando Python.

O projeto realiza manualmente o cálculo do histograma, da CDF (*Cumulative Distribution Function*) e das LUTs (*Look-Up Tables*), utilizando o OpenCV principalmente para leitura, exibição e salvamento das imagens.

---

## 🎯 Objetivos

O projeto possui os seguintes objetivos:

- Carregar imagens em escala de cinza;
- Calcular e visualizar seus histogramas;
- Implementar a equalização de histograma;
- Implementar a especificação de histograma;
- Utilizar uma imagem de referência para definir a distribuição desejada;
- Comparar visualmente as imagens e seus histogramas.

---

## 🛠️ Tecnologias utilizadas

- **Python**
- **OpenCV**
- **NumPy**
- **Matplotlib**
